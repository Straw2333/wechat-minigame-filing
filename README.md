# wechat-minigame-filing

WeChat Mini Game compliance qualification, pre-approval materials generation, and MIIT ICP filing workflow.

## Overview

This tool assists developers in preparing compliance assets and automating the pre-approval submission process on the WeChat Mini Game platform.

### Capabilities
- Screenshot asset generation with official UI capsule and naming overlay.
- Automated self-audit report generation.
- Structured pre-approval text verification.
- End-to-end guidance for MIIT ICP registration.

## Usage

Place this skill into your agent's skills directory or invoke directly via compatible CLI runners.
