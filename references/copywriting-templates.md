# 微信小游戏备案与前置审批标准文案模板库

> 适用对象：纯 IAA（激励广告变现、无内购充值）或轻度休闲微信小游戏。使用时将 `{{...}}` 占位符替换为目标游戏真实信息，并确保游戏名称与微信公众平台登记名称完全一致。

## 1. 禁忌词汇排查清单（填报前必查）

在纯 IAA 单机小游戏填报文案中，**严禁出现**以下词汇，否则极易触发版号核查或被人工驳回：
* 支付/氪金类：`充值`、`首充`、`月卡`、`VIP`、`氪金`、`付费购买`、`商城交易`、`钻石直购`、`人民币`、`提现`、`现金红包`
* 博彩/违规类：`抽奖必中`、`赌博`、`押注`、`老虎机`、`性感`、`血腥`、`暴力击杀`
* 夸大绝对化：`第一`、`最强`、`全网最火`、`极品必爆`

## 2. `new-pre-approval-file` 第②步标准文本模板

### 2.1 1. 场景 -> 各主要场景描述（要求 ≥ 30 字）
```text
游戏主界面风格：游戏采用{{ART_STYLE}}画风与清晰直观的界面交互。主界面与游玩界面以{{SCENE_LIST}}为核心场景背景，展现{{SCENE_ACTION_DESC}}的生动画面，整体视觉风格健康纯净、轻松解压。
```
*长度参考*：约 100~160 字。

### 2.2 2. 玩法 -> 整体玩法设计（要求 ≥ 50 字）
```text
具体玩法为：
1. 核心操作：玩家通过{{CORE_INPUT_ACTION}}，推进关卡进度并获取基础游玩反馈；
2. 循环成长：使用游玩过程中免费产出的资源{{PROGRESSION_LOOP}}，提升综合效率；
3. 养成进阶：解锁{{UPGRADE_SYSTEMS}}等成长要素，体验逐步深入的策略乐趣；
4. 关卡目标：循序完成{{LEVEL_GOALS}}等主题关卡挑战。
```
*长度参考*：约 150~220 字。

### 2.3 3. 系统1 -> 货币系统说明（要求 ≥ 30 字）
```text
本游戏为完全绿色的单机休闲体验，不包含任何形式的游戏内充值、虚拟货币购买或微交易商城。游戏内仅包含通过玩家正常游玩免费产出的{{FREE_CURRENCY_NAMES}}，用于{{CURRENCY_USAGE}}，杜绝任何诱导消费。
```
*长度参考*：约 90~130 字。

### 2.4 3. 系统2 -> 道具系统说明（要求 ≥ 30 字）
```text
游戏内包含{{ITEM_SYSTEM_NAMES}}等辅助养成道具元素。游戏内所有道具与能力均可通过正常游戏游玩免费解锁获取，不设任何付费道具或内购商城；仅在玩家主动点击获取额外辅助增益时触发非强制性纯激励视频广告。
```
*长度参考*：约 100~140 字。

### 2.5 3. 系统3 -> 设置系统说明（要求 ≥ 30 字）
```text
本游戏具备完备的通用设置系统，支持玩家在游玩过程中随时自主调节背景音乐（BGM）、动作音效（SFX）以及触觉震动反馈强弱档位；设置状态支持本地自动持久化保存，保障流畅纯净的单机游玩体验。
```
*长度参考*：约 93 字（可直接复用，无需大幅修改）。
