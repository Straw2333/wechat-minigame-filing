# 微信小游戏前置审批页面 (`new-pre-approval-file`) 填报与自动化规范

页面路径：`https://mp.weixin.qq.com/wxamp/subApp/game/minigame/new-pre-approval-file`

## 1. 三步向导结构与核心规则

页面为三步向导流程：**① 游戏类型及相关文件 ➔ ② 填写游戏内容 ➔ ③ 信息预览**。

### 1.1 第①步：游戏类型及相关文件
* **游戏名称**：平台自动关联且不可编辑（**务必记录此正式名称**，可能包含副标题，与代码内部名称不同；后续所有截图均须展示该正式名称）。
* **游戏类型**：休闲单机优先选 `休闲类 - 模拟经营` 或 `休闲类 - 益智` 等无需重度版号类目。
* **网络类型**：单机玩法选择 `单机`（单机模式下广告变现、防沉迷不计入自身联网交互系统）。
* **电子签署文件**：《著作权自我声明》《代备案授权书》《单机承诺函》需管理员在页面引导下微信扫码完成电子签。

### 1.2 第②步：填写游戏内容（硬性校验与避坑清单）

| 区域 | 字数要求 | 截图要求 | 关键防踩坑说明 |
| :--- | :--- | :--- | :--- |
| **1. 场景（各主要场景描述）** | ≥ 30 字，≤ 800 字 | **≥ 3 张** | 写明美术风格、核心主界面与代表性关卡场景 |
| **2. 玩法（整体玩法设计）** | ≥ 50 字，≤ 800 字 | **≥ 3 张** | 分点写明核心操作、核心循环、养成进阶与关卡目标 |
| **3. 系统1** | ≥ 30 字，≤ 800 字 | **≥ 1 张** | 推荐选 **货币系统**（明确免费产出游戏内资源，零充值） |
| **3. 系统2** | ≥ 30 字，≤ 800 字 | **≥ 1 张** | 推荐选 **道具系统**（明确全部免费解锁，激励广告非强制） |
| **3. 系统3** | ≥ 30 字，≤ 800 字 | **≥ 1 张** | **平台限制：系统功能最少为 3 个**，不能删除成 2 个！纯单机推荐选 **设置系统**（BGM/SFX/震动调节） |
| **选填项**（背景/角色/NPC/情节/特点） | 默认不开启 | 若开启则每项需 **≥ 3 张** | **保持默认“本游戏不涉及”**，避免平白增加大量额外截图要求 |

### 1.3 截图审核硬性标准
1. **格式与大小**：`JPG`、`JPEG` 或 `PNG`，单张 **60 KB ~ 5 MB**。
2. **微信环境特征**：画面内必须包含微信小游戏顶部**胶囊按钮**（`... | ◎`），且画面内显示的小游戏名称必须与第①步后台登记名称**一字不差**。

## 2. 浏览器子代理（Browser Subagent）填报 SOP

使用 `browser` 子代理（默认 `Model: "flash"`）访问目标 URL 时遵循以下协议：

1. **登录态处理（`BLOCKED / AUTH_REQUIRED`）**：
   * 独立浏览器无个人微信公众平台 Cookie，首次打开可能提示“登录超时，请重新登录”并跳转扫码页。
   * 暂停并提示用户在右侧内置浏览器面板微信扫码登录；用户确认已登录后，通过 `send_message` 唤醒**同一个** `conversationId` 继续操作，禁止新建子代理覆盖当前已登录标签页。
2. **沙箱文件暂存（关键！）**：
   * 将 `prepare_wechat_screenshots.ps1` 生成的截图复制到 `<Artifact Directory Path>/browser_sandbox/uploads/`，使用单层文件名供 `setInputFiles` 调用。
   * **注意生命周期**：`browser_sandbox/uploads/` 在子代理回合退出或跨域跳转后会被自动清空。每次通过 `send_message` 续传截图前，**必须先检查并重新拷贝文件到 `uploads/`**。
3. **保存与超时防丢（`OP_TIMEOUT`）**：
   * 表单填入大段文本后，应指示子代理先点击一次【保存】按钮（确认 `draftgameintro` 接口返回 `200` 并提示“保存成功”），再推进上传截图，防止页面挂起刷新丢失已填文案。
   * 若遇 `OP_TIMEOUT`，切勿盲目整页刷新覆盖未保存文本，先提示用户检查浏览器窗口是否有阻塞的原生文件选择弹窗。
4. **最终提交红线**：
   * 完成所有文本与截图上传并点击【保存】➔ 点击【下一步】进入 **第③步「信息预览」**（确认 `visibleErrs` 为空且所有缩略图渲染正常）后立即停止，**严禁代用户点击最终绿色“提交”按钮**，请用户复核整页预览后手动确认提交。
